AuthRecon Testing URLs

When testing with AuthRecon, use these internal Docker network URLs:

⚠️ Important: From inside Docker containers (like AuthRecon worker), use:
  • http://loginlab:5500/basic-auth
  • http://loginlab:5500/form-login
  • http://loginlab:5500/multi-step
  • http://loginlab:5500/sso-redirect
  • http://loginlab:5500/ldap-login
  • http://loginlab:5500/api/auth
ℹ️ Browser Testing: From your browser, use:
  • http://localhost:5100/basic-auth
  • http://localhost:5100/form-login
  • etc.

API Endpoints

  • GET /health - Health check
  • GET /scenarios - List all scenarios (JSON)
  • GET /metrics - Get testing metrics
  • GET /telemetry - View captured telemetry
  • POST /reset - Reset all sessions and telemetry
